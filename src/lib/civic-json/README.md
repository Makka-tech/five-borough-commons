# civic.json adapter

Five Borough Commons can import and export a small portable subset of common civic-tech project metadata: `name`, `description`, `repository`, `homepage`, `status`, `tags`, and optional public contact details.

The adapter does not treat `civic.json` as the source of truth. It cannot represent Five Borough Commons fields for resident value, non-goals, stewardship, privacy limitations, contribution task acceptance criteria, impact evidence, or project lifecycle reviews. Imported entries must be enriched and pass the registry schema before publication.
