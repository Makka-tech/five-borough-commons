# Need triage rubric

Ask: Is the resident need real and sufficiently specific? Does relevant work exist? Is software appropriate, or would a guide, correction, or research note work better? Is it safe? Can it be maintained? Is a prospective steward available? Are affected residents involved? Record one lifecycle outcome: Submitted, Needs clarification, Researching, Validated need, Project candidate, Accepted for incubation, Not suitable for software, Merged with existing work, or Closed with resources.
