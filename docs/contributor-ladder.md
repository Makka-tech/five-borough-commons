# Contributor ladder

**Participant** joins respectfully; **Contributor** makes a useful contribution; **Regular Contributor** reliably supports project work; **Reviewer** gives careful, constructive review; **Project Maintainer** stewards an individual project; **Community Steward** supports cross-project governance and care. Examples include need intake, documentation, translation, user testing, accessibility, data validation, mentoring, meeting facilitation, release care, and responsible conflict support. Roles are behavior-based, never commit-count thresholds.
