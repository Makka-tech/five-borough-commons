# Label taxonomy

Use labels to make work discoverable, never to rank people: `good first issue`, `help wanted`, `mentor available`; tracks `track:code`, `track:data`, `track:design`, `track:docs`, `track:translation`, `track:research`, `track:testing`, `track:accessibility`, `track:outreach`; efforts `effort:15m`, `effort:1h`, `effort:half-day`, `effort:ongoing`; difficulty `difficulty:starter`, `difficulty:intermediate`, `difficulty:advanced`; status `status:needs-triage`, `status:ready`, `status:blocked`, `status:in-progress`; and borough coverage labels.
