# 30-day community launch plan

## Before launch

Establish the GitHub organization; publish governance; create beginner tasks; prepare truthful project descriptions; test onboarding with two or three people; identify a founding maintainer and potential reviewer; publish the first RFC.

## Launch week

Publish the site and roadmap; invite work across multiple tracks; run one public orientation; acknowledge every genuine contribution; and record questions that reveal documentation gaps.

## Following weeks

Review the first-contributor experience; publish community notes; improve task quality; recruit co-maintainers; publish a small release; and review whether each project still has responsible stewardship. Do not use spam or artificial growth tactics.
