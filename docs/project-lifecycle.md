# Project lifecycle

**Proposed** is unvalidated; **Discovery** researches the need and alternatives; **Prototype** tests a limited implementation; **Pilot** collects feedback with real users or a verified community partner; **Maintained** has purpose, maintainer, roadmap, contribution, support, release process, and recent stewardship review; **Needs maintainer** remains useful but lacks stewardship; **Paused** documents why work stopped; **Archived** documents why it ended or was superseded. Archiving is responsible maintenance, not failure.
